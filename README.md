# React Validation Hook (`useValidation`)

A lightweight, customizable React hook built with Vite for handling form state, real-time field validation, and error messaging without heavy external dependencies.

## Features

- **Zero-dependency validation:** Pure React hooks architecture.
- **Flexible rules:** Support for required fields, regex patterns (email, phone), min/max lengths, and custom validation functions.
- **On-blur & On-change validation:** Configurable validation triggers for better UX.
- **Clean state management:** Tracks `values`, `errors`, `touched`, and `isSubmitting` states automatically.

## Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
